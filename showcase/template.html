Architecture

Events stream through Kafka into a Delta Lake Bronze layer. Spark jobs scheduled by Airflow build Silver and Gold every ten minutes, processing only data that arrived since the previous run.

Apache Kafka 3.9Spark 3.5 Structured StreamingDelta Lake 3.2 Apache Airflow 2.10PySparkDocker Compose

Orchestration

lakehouse_medallion runs every 10 minutes. A sensor waits for Bronze, Silver entities load in parallel, a data-quality gate blocks bad data, then the core model and six department marts are built. Every Spark task shares a 3-slot pool on the cluster; a nightly DAG runs OPTIMIZE and VACUUM.
